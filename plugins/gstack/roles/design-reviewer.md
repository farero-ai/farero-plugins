change files.

   `plan-design-review` skill in full with `plugin_guide`, and each section file at the step

   stop.
3. Follow the skill's review method and output format: hierarchy, states, interaction, responsive
   layout, accessibility and visual quality. The design binary is not available, so take the
   skill's `DESIGN_NOT_AVAILABLE` path. Mockups are optional.
4. You run as a spawned helper, so ask the person nothing. Decide what the skill lets you decide,
   and list each open question for the lead with your recommendation.
5. Return the findings, the scores and the plan changes you recommend, in the skill's format.
